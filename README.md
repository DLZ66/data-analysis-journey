## 项目简介

<!-- 一句话说清你在做什么。样例： -->
本仓库记录我从零学习数据分析的全过程，包含每周练习、综合小作业和两个正式项目。
最终目标是把材料/工艺数据用机器学习和实验设计的方法做出可落地的预测与推荐。
